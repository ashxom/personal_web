## 퍼스널 컬러 진단 & 스타일링 웹페이지
### 프로젝트 소개
퍼스널 컬러(봄웜/여쿨/가을웜/겨쿨) 진단 결과에 따라 맞춤형 스타일링 콘텐츠를 보여주는 반응형 웹페이지입니다. 순수 HTML/CSS/JavaScript 단일 파일로 제작되어 별도 서버나 빌드 과정 없이 브라우저에서 바로 실행됩니다.

### 주요 기능
- 메인 페이지: 4가지 퍼스널 컬러 타입(봄웜/여쿨/가을웜/겨쿨) 카드 리스트, 무료 진단 페이지 연결
- 시즌별 상세 페이지: 타입별 테마 컬러링(그라데이션 배경, 포인트 컬러) 적용된 개인 맞춤 공간
- 화장대 캐러셀: 각 시즌에 어울리는 실제 화장품 제품 이미지 표시 → 클릭 시 올리브영/브랜드 공식몰 상품 페이지로 이동
- 인터랙티브 옷장: 클릭하면 문이 열리며 해당 시즌 팔레트 컬러 캡슐 5종 표시
- 스타일링 꿀팁: 액세서리, 메이크업, 헤어 컬러 추천 문구
- 네비게이션: 상세 페이지 → 메인 페이지 뒤로가기 버튼

### 기술 스택
- HTML5 / CSS3 (Flexbox, CSS 변수 기반 테마 시스템)
- Vanilla JavaScript (페이지 전환, 캐러셀 스크롤, 옷장 토글)
- 이미지: Base64 인코딩으로 파일 내 직접 삽입 (외부 의존성 없음)
