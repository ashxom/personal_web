## **Colory**

**퍼스널 컬러 스타일링 웹페이지**

제작기간 : 7월 20일~22일

제작인원 : 개인 프로젝트

배포 URL : https://ashxom.github.io/personal_web/

## 프로젝트 소개

JUMP UP CAMP figma 수업에서 직접 디자인하여 퍼스널 컬러를 처음 접하거나 진단 결과를 실제 스타일링에 어떻게 활용할지 어려워하는 사용자를 위해 만든 웹페이지입니다. 단순히 봄웜·여쿨·가을웜·겨쿨 결과만 보여주는 데 그치지 않고, 각 톤에 어울리는 메이크업 제품, 추천 컬러, 스타일링 팁을 한 화면에서 직관적으로 확인할 수 있도록 구성했습니다. 사용자가 자신의 퍼스널 컬러에 맞는 쇼핑과 스타일링을 더 쉽고 즐겁게 시작하는 것을 목표로 합니다.

### **기술 스택**

- HTML5 / CSS3 (Flexbox, CSS 변수 기반 테마 시스템)
- Vanilla JavaScript (페이지 전환, 캐러셀 스크롤, 옷장 토글)
- 이미지: Base64 인코딩으로 파일 내 직접 삽입 (외부 의존성 없음)

### **AI 활용 및 검토 과정**

사용한 AI : Codex

AI에게 맡긴 작업 : 전체적인 웹 구현 틀 잡기

직접 수정 및 개선한 내용 : 잘못된 링크나 부분적인 디자인 수정

### 주요화면 및 구현 내용

- 메인 페이지: 4가지 퍼스널 컬러 타입(봄웜/여쿨/가을웜/겨쿨) 카드 리스트, 무료 진단 페이지 연결
- 시즌별 상세 페이지: 타입별 테마 컬러링(그라데이션 배경, 포인트 컬러) 적용된 개인 맞춤 공간
- 화장대 캐러셀: 각 시즌에 어울리는 실제 화장품 제품 이미지 표시 → 클릭 시 올리브영/브랜드 공식몰 상품 페이지로 이동
- 인터랙티브 옷장: 클릭하면 문이 열리며 해당 시즌 팔레트 컬러 캡슐 5종 표시
- 스타일링 꿀팁: 액세서리, 메이크업, 헤어 컬러 추천 문구
- 네비게이션: 상세 페이지 → 메인 페이지 뒤로가기 버튼

## 프로젝트 회고

이번 프로젝트를 통해 HTML, CSS, JavaScript를 이용해 웹페이지를 만들고 GitHub Pages로 직접 배포하는 과정을 경험할 수 있었습니다. 안드로이드 개발만 해오다가 처음으로 웹을 배포해 보니 별도의 서버 없이 GitHub만으로 손쉽게 서비스를 공개할 수 있다는 점이 인상 깊었습니다. 또한 퍼스널 컬러별 분위기를 고려해 색상과 레이아웃을 구현하면서 디자인을 코드로 표현하는 방법도 배울 수 있었습니다.

다음에는 다양한 화면에서도 보기 편하도록 반응형 디자인을 보완하고 사용자가 직접 질문에 답하면 퍼스널 컬러를 진단받을 수 있는 기능을 추가해 보고 싶습니다. 또한 추천 상품 데이터를 효율적으로 관리하고 사용자 선택 결과를 저장하는 기능까지 구현해 실제 서비스에 더 가까운 프로젝트로 발전시켜 보고 싶습니다.
